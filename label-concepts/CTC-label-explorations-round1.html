01

Call Sheet

Clean, type-forward, zero decoration. Reads like a production document — the label version of a call sheet. The most professional of the six; disappears into a Google or UA set without asking for attention.

actual print size — 50 × 30 mm

Variable data

  • Name — hero size, left-aligned, auto-shrinks for long names
  • Drink — single line under the name, midline dots for mods
  • Order № — top right, always same spot
  • Production + day — bottom left rule line
02

Big Smile

The existing smiley asset, finally given a real layout instead of floating alone. Brand mark left, order data right. Playful crew energy; closest evolution of what's in the app today.

actual print size — 50 × 30 mm

Variable data

  • Smiley — fixed left, never scales
  • Name — hero, top of text column
  • Drink + mods — two lines below
  • Order № — anchored bottom right
03

Rubber Stamp

Heavy double border, everything centered — an official seal of crew approval. The only concept where the DRINK is the hero instead of the name. Bold, graphic, prints like a dream on thermal.

actual print size — 50 × 30 mm

Variable data

  • Drink — hero, centered, condensed + auto-shrink for long drinks
  • Name — 'FOR:' line under the hero
  • Order № + status — bottom stamp line
  • Brand — arced-style top line inside the border
04

Ticket Stub

Admit-one ticket with a tear-off stub. The order number lives sideways on the stub — playful, but it's also the most operational layout: a PA can read the № without turning the cup.

actual print size — 50 × 30 mm

Variable data

  • Drink — hero, left block
  • Name + ADMIT ONE — ticket holder line
  • Production / day / time — bottom line
  • Order № — rotated 90° on the stub, oversized
05

Knockout

Full-bleed black, white type. Closest to the black-square logo energy and spottable across a set instantly — no other cup on craft services will look like this. Wordmark shown as placeholder italic; final art would use the brand script.

actual print size — 50 × 30 mm

Variable data

  • Wordmark — top left, fixed
  • Name — hero, biggest type of any concept
  • Drink — under the white rule
  • Day/scene + order № — bottom corners
06

Ladder Crew

The on-set character redrawn as thermal-safe linework: crew member up a ladder, handing your coffee down. The warmest and most illustrated take — merch-ready if the brand grows into it.

actual print size — 50 × 30 mm

Variable data

  • Name — hero, left text block
  • Drink — under the name
  • Order № / day / temp — bottom rule line
  • Character — fixed right, never scales, bleeds off bottom
Notes for picking a direction.

Every mockup above is rendered at the true printhead resolution (567 × 340 px) — what you see is what the M2_H prints, no color or gradients faked. Print-ready PNGs for all six live in label-concepts/print-png/, ready to test-fire on the actual roll.

All six handle the same variable data — name, drink + mods, order number, production/day — they just disagree about which one is the hero. Long names and drink strings auto-shrink the same way the current app labels do. Concept 05 uses the most ink (solid black flood); worth one physical test print before committing to it.
